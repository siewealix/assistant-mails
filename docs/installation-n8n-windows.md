# Installation de n8n sous Windows

## Objectif

Cette étape permet d’installer n8n en local afin d’automatiser la récupération, le résumé et l’envoi des e-mails.

## Vérification de Node.js

Commande utilisée :

```powershell
node -v

n8n nécessite une version de Node.js compatible.

Installation de n8n

Commande utilisée :

npm install n8n -g
Vérification de n8n

Commande utilisée :

n8n --version
Lancement de n8n

Commande utilisée :

n8n

Adresse locale utilisée :

http://localhost:5678
