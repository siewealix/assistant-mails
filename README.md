# Assistant Mails Stage

Application web développée avec React et automatisation avec n8n.

## Objectif du projet

Ce projet permet de consulter les e-mails reçus dans la journée, de générer un résumé global avec OpenAI, puis de répondre aux e-mails depuis une interface web.

## Technologies utilisées

- React
- Vite
- n8n
- Gmail
- OpenAI API
- GitHub
